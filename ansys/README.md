# ANSYS Project Files

The analysis was developed in ANSYS Workbench / Mechanical 2026 R1.

The full Final A2 Workbench archive is approximately **900 MB** and is distributed through GitHub Releases rather than stored in the normal Git history. A `.wbpz` archive is used because a standalone `.wbpj` file depends on its associated project-data directory.

## Final A2 Workbench archive

- Release: [v1.0](https://github.com/Tonylo-lab/pneumatic-gripper-fea/releases/tag/v1.0)
- Archive: [pneumatic_gripper_case_A2_final.wbpz](https://github.com/Tonylo-lab/pneumatic-gripper-fea/releases/download/v1.0/pneumatic_gripper_case_A2_final.wbpz)

Baseline, Case A1, and topology-optimization results are documented in the repository through the methodology, result workbook, figures, and CAD geometry. The archived Workbench project contains the final nonlinear A2 validation model.

Large solver-generated files and unpacked Workbench cache directories are excluded from version control.
